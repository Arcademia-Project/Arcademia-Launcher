# Arcademia-Launcher
 A WPF App for the Arcademia arcade machines.
## Setup
  No `Config.json` file required but the [Arcademia-Updater](https://github.com/Arcademia-Project/Arcademia-Updater "GitHub.com") is required which you will contain the `Config.json`. Button mapping is configured in the Launcher.
### [Latest Release](https://github.com/Arcademia-Project/Arcademia-Launcher/releases/latest "GitHub.com")
## Information
  To run this system on an arcade machine you will need to launch this program using the [Arcademia-Updater](https://github.com/Arcademia-Project/Arcademia-Updater "GitHub.com").
  For further information, please refer to the [Docs](https://github.com/Malphatt/Arcademia-Dev-Guide/wiki)
